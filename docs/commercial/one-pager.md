# Protocol One-Pager

**Name:** Witness Circles

**Tagline:** Sign one Bitcoin moment together.

**Protocol:** `WITC` v1

**Primitive:** Native P2TR key-path coauthorization plus one conservative `OP_RETURN`

**Participants:** 2 to 16

**Asset:** None

**Market:** None
**Mainnet status:** Experimental, not production enabled

## User action

Contribute one confirmed dedicated Taproot input, preview exact public linkage and fee, sign the complete transaction, and receive the Bitcoin back to the same key minus an equal fee share.

## Verifiable result

Bitcoin establishes the exact input keys, outputs, fee, block position, signatures, and history. Optional context is hash-committed. Indexers derive participant lineages without a proprietary API.

## Partner value

- Wallets: differentiated, human-readable collaborative signing
- Explorers: visually distinctive transaction and lineage graphs
- Creators: verifiable shared release moments without issuing assets
- Data platforms: deterministic decoding and protocol health data
- Communities: recurring collaboration history without reward farming

## Main risks

Permanent public linkage, multi-wallet friction, coordinator stalling, fee volatility, device display limitations, and Sybil keys.

## Launch gates

Two independent indexers, 30-day Signet pilot, zero high security findings, representative hardware-wallet results, strong privacy comprehension, at least 80 percent session completion, and at least 20 percent 30-day repeat participation.
