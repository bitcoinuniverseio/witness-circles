# Partner Integration Brief

## Wallet partners

The value is a safe, decoded collaborative signature flow. Required capabilities are native P2TR discovery, signer-specific PSBTs, complete transaction display, non-finalized Taproot contributions, protected shards, explicit closure, and unanimous RBF.

Hardware support is declared per model and firmware after testing. Unsupported devices must fail clearly before a user contributes an input.

## Explorer and data partners

The protocol offers deterministic marker, fee, signature, lineage, replacement, conflict, and reorganization data. It does not offer balances, supply, prices, transfers, or floor data. Public APIs should include raw evidence and parser versions.

## Creator and event partners

Partners can host contexts and custom renderers while users retain custody. Event services may charge disclosed service fees outside the protocol. No partner can guarantee attendance, uniqueness of people, future value, or permanent metadata availability.

## Commercial model

Sustainable services can include managed coordination, high-availability indexing, private manifest preservation, branded accessible renderers, enterprise event operations, support, and data APIs. The protocol itself remains independently verifiable.

## Due diligence package

Partners should review the specification, security policy, golden vectors, package lock, deployment model, privacy disclosure, incident process, device matrix, accessibility results, and Signet pilot metrics before launch.
