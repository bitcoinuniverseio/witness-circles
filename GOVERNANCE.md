# Governance

Witness Circles is an open protocol specification, not an administrative key or voting system.

## Decision process

Material changes begin as written WITC Improvement Proposals. A proposal must state its problem, normative change, compatibility impact, threat model, privacy impact, test vectors, activation plan, alternatives, and rollback strategy.

Protocol version changes require:

1. Public review period of at least 30 days
2. Two independent parser implementations
3. Cross-implementation vector agreement
4. Wallet safety review
5. Reorganization and historical replay tests
6. Documented deployment and activation policy

Maintainers can merge documentation and implementation changes, but cannot make unsupported transactions valid by repository decree. Indexers choose software and parser versions. Bitcoin users choose wallets and applications.

## Conflicts

Security fixes may use a private embargo. Commercial urgency, market demand, or application schedules are not reasons to skip deterministic review.

No token, fee entitlement, company ownership, or repository contribution grants protocol governance power.
