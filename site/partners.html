Partner paths

Add a shared Bitcoin signature, not another asset.

The commercial opportunity is coordination, safe signing, verification, accessible rendering, event operations, and reliable data.

Wallets

Decoded confidence

Dedicated coin selection, complete transaction review, signer-minimized PSBTs, protected shards, explicit closure, and unanimous RBF.

Explorers

Raw proof plus context

Marker bytes, signatures, fee shares, lineage edges, replacement and reorg state, accessible constellations, and parser versions.

Creators

Real collaborative releases

Host meaningful contexts and visual renderers without issuing a token, royalty, or attendance credential.

Data platforms

Deterministic event data

Decode activity, costs, concentration, lineages, conflicts, and invalid candidates. Do not invent balances or prices.

Communities

History without reward farming

Mark recurring work, releases, and collaborations with optional invitations and honest event expiry.

Operators

Managed reliability

Offer high-availability coordination, indexing, manifest preservation, rendering, support, and monitoring while protocol verification stays open.

Due diligence

Review before integration.

Partners should reproduce the golden vector, review the lockfile and package digest, map data flows, test representative wallets, assess public-linkage comprehension, define incident roles, and obtain qualified legal review for actual jurisdictions.

The source repository is public for technical review. No verified partner contact route, deployment, or active onboarding program is claimed.
