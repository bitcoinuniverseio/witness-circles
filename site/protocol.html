Normative model

One operation. Every byte accounted for.

Version 1 recognizes only CIRCLE. The compact grammar leaves transfer, markets, refueling, rekeying, and CPFP out on purpose.

Claim boundary: distinct P2TR output keys authorized this exact transaction. The protocol does not prove identity, attendance, friendship, endorsement, or one key per person.

Marker

Output zero has value zero and exactly 42 script bytes: OP_RETURN PUSH40, followed by a 40-byte payload.

offset 0  · 4 bytes  · ASCII WITC
offset 4  · 1 byte   · version 01
offset 5  · 1 byte   · network 00..03
offset 6  · 1 byte   · operation 01 CIRCLE
offset 7  · 1 byte   · participant count 02..10 hex
offset 8  · 32 bytes · SHA256 context hash

Direct PUSH40 is mandatory. Alternate pushes, trailing bytes, unknown version or operation, and a zero context hash are invalid.

Transaction grammar

  1. Transaction version 2, locktime zero, and every sequence 0xfffffffd.
  2. Two to sixteen confirmed native P2TR inputs from lower block heights.
  3. Distinct outpoints and distinct output keys.
  4. Inputs strictly sorted by display txid bytes, then numeric vout.
  5. Output zero is the marker; output i + 1 repeats input i's exact script.
  6. Each successor is at least 1,000 sats.
  7. One key-path Schnorr witness per input, using default or all-output sighash only.

Equal fee allocation

F = sum(inputs) - sum(successors)
q = floor(F / N)
r = F mod N

slot i pays q + 1 when i < r, otherwise q

The canonical sort makes remainder assignment deterministic. Wallets set fee caps; the protocol does not set a maximum market fee.

Context

The optional human context is strict JSON, canonicalized by RFC 8785 and hashed with SHA-256. Only the hash enters Bitcoin. A lost or private manifest does not invalidate the Circle. Applications treat every manifest field as untrusted presentation data.

Lineages

A fresh input derives a lineage ID from the domain WITC/lineage/v1 plus its Bitcoin wire outpoint. The same-script successor becomes the active shard. A later valid Circle continues it. Any ordinary spend closes it without burning Bitcoin.

Mempool and reorganization

Mempool status is local and provisional. RBF needs every participant to sign the replacement. Confirmed state follows Bitcoin's best chain. Indexers reverse events to the common ancestor and replay the new branch in transaction order.

Version 1 exclusions

No transfer, split, merge, refuel, rekey, mint, reward, token, governance action, administrative override, marketplace operation, or CPFP flow exists. Unknown operations are rejected, not inferred.

Upgrade rule

A new behavior needs a new version byte, specification, threat model, schemas, vectors, independent parser agreement, wallet review, and activation policy. A later release cannot reinterpret v1 history.
