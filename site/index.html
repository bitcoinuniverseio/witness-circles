Know the tradeoff

Public co-spending is the feature and the risk.

A Circle intentionally links every participant input and every same-key continuation. Dedicated UTXOs reduce unrelated exposure, but they do not create privacy.

Never use Witness Circles as proof of a person. Keys can be shared, automated, sold, or controlled by the same party. Read the complete threat model before testing with funds.
