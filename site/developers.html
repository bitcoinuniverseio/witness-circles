Reference flow

Every projection starts at Core.

1

Decode strictly

Reject nonminimal CompactSize values, ambiguous marker pushes, extra bytes, unknown operations, and integer overflow.

2

Validate completely

Load every confirmed prevout, enforce output mapping and fee shares, then verify each output-key signature.

3

Project reversibly

Apply lineages atomically, separate mempool state, checkpoint hashes, and reverse to the common ancestor on reorg.

Wallet boundary

Each signer validates the complete unsigned transaction independently. Derivation paths are shown only to their owner. Contributions remain non-finalized Taproot key signatures.

Metadata boundary

Manifest retrieval is optional and untrusted. A parser never requests a URL, profile, image, or proprietary API to decide validity.

Implementing another language? Begin with the marker and golden transaction. Publish your parser version and state hash. A matching marketing description is not an interoperability result.
