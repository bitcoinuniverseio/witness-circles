First transaction checklist

Five checks before a signature.

1. Dedicated input

Confirmed native P2TR, not connected to unrelated funds or protocol assets.

2. Exact context

The locally canonicalized manifest hash matches the marker.

3. Complete outputs

One zero-value marker and one same-key successor for every input.

4. Honest fee

Your exact fee share and total rate remain within caps you selected.

5. Safe signature

Default or all-output Taproot key-path sighash, with no annex or script path.
